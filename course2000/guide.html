使用说明

1 · 安装 / 下载与解压

推荐：从「下载」页获取 Course2000Setup.exe（55 KB），运行后选安装位置，安装器自动下载完整包、校验、解压并创建桌面快捷方式与卸载入口，全程无需手动干预。装好后目录结构如下。

手动方式：下载 Course2000-Windows.zip（约 88.5 MB，含 4019 个文件），右键 → 全部解压，得到三层结构：

  • Course2000.exe — 单文件桌面程序（816 KB，C# + WebView2）
  • course2000/ — 课程目录：index.html + 2007 课 lesson-XXX.html + showcase.html
  • Course2000-PPTX课件-2007课/ — 2007 课 PPTX + 总目录 + 检索页

务必保证 Course2000.exe 与 course2000/ 文件夹在同一目录——程序按相对位置加载课程。课件 PPTX 文件夹可放任意位置，独立使用。

⚠️ 打开 PPTX 总目录前，请先把整个 zip 完整解压。直接在压缩包内双击 Course2000-总目录.pptx，其相对超链接指向的 2007 个单课文件不存在，会报「指定的文件不存在」。

2 · 运行前提：WebView2 Runtime

Windows 10 / 11 普遍已随 Microsoft Edge 预装 WebView2 Runtime，双击 exe 即可。若提示「WebView2 内核初始化失败」：

  • 到微软官网搜索并下载 「WebView2 Evergreen Standalone Installer」，装一次即可（约几十 MB，常驻系统）。
  • 无需其他依赖：程序不依赖 Electron / Node / Python / 浏览器安装。
  • 详细异常会写入程序目录 build/error.log，便于排查。

3 · 打开课程（Windows exe）

  • 双击 Course2000.exe，窗口立即弹出并显示加载动画，引擎后台初始化、课程就绪后无缝切换，不等白屏。
  • 默认最大化启动（最小 900×600）；支持窗口内右键菜单与快捷键。
  • 用户缓存目录固定到程序自身目录（cache/），二次启动复用缓存、明显提速。
  • 想换位置：连文件夹一起移动即可，无注册表残留。
未购买代码签名证书，首次运行 Windows / Edge 可能提示「发布者未知」（SmartScreen）。点「更多信息」→「仍要运行」，或下载面板选「保留文件」即可，之后不再提示。

4 · macOS / Linux 开课

不装 exe 也能学，两条路任选：

  • 浏览器直接开：解压后，用任意现代浏览器打开 course2000/index.html，功能与 exe 内完全一致（exe 只是提供原生窗口与启动优化）。
  • py 生成器：下载 gen_course.py（24 KB，纯 Python 3 标准库、零依赖），在脚本目录执行 python3 gen_course.py 生成 course.html 课程页，浏览器打开即学。改文件顶部 UNITS 数据即可产出自己的课程。

macOS / Linux 没有 WebView2，因此桌面 exe 不支持；上述两种方式在 Unix 系统下体验与 Windows 等效。

5 · 目录结构

Course2000/
├─ Course2000.exe                 ← 单文件桌面程序（Windows）
├─ course2000/                    ← 课程站（纯静态 HTML）
│  ├─ index.html                  ← 课程目录页（检索 + 94 单元分区）
│  ├─ lesson-001 … lesson-2007.html
│  └─ showcase.html               ← 毕业作品：能力展示台
├─ Course2000-PPTX课件-2007课/    ← 独立课件包（PowerPoint / WPS）
│  ├─ lesson-001 … lesson-2007.pptx
│  ├─ Course2000-总目录.pptx      ← 2007 条超链接，直达每一课
│  └─ index.html                  ← 课件检索页
└─ cache/                         ← exe 运行缓存（可删，首次加载略慢）

6 · 常见问题

启动提示「WebView2 内核初始化失败」怎么办？
说明系统缺少 Microsoft Edge WebView2 Runtime。到微软官网搜索「WebView2 Evergreen Standalone Installer」下载安装一次即可；详细异常写入程序目录 build/error.log。
不装 exe，能直接看课程吗？
可以。课程是纯静态 HTML，解压后用任意现代浏览器打开 course2000/index.html 即可，功能与 exe 内一致。
macOS / Linux 怎么用？
浏览器直接开 course2000/index.html，或下载 gen_course.py 在本机 python3 gen_course.py 生成课程页学习（Python 3.8+，无需第三方库）。
换电脑 / 换文件夹，学习进度会丢吗？
课程站本身不记录个人进度，把整个文件夹拷过去即可。exe 生成的 cache/ 缓存目录删除不影响课程内容，只是首次加载略慢。
PPTX 课件在哪里？
PPTX 课件在 zip 内的 Course2000-PPTX课件-2007课/，先完整解压 zip 后使用。
zip 校验值怎么用？
Windows PowerShell 执行 Get-FileHash Course2000-Windows.zip -Algorithm MD5，与「下载」页值比对一致即说明文件完整未被篡改。
