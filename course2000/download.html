三步使用

解压 zip

右键 → 全部解压。保证 Course2000.exe 与 course2000/ 文件夹在同一目录——程序按相对位置加载课程。

确认 WebView2 Runtime

Windows 10/11 普遍已随 Edge 安装。若启动报「WebView2 内核初始化失败」，到微软官网下载「Evergreen Standalone Installer」装一次即可。

双击 Course2000.exe 开课

首次启动稍慢（初始化缓存），之后明显提速。想换位置，连文件夹一起移动即可，无注册表残留。

常见问题

启动提示「WebView2 内核初始化失败」怎么办？
说明系统缺少 Microsoft Edge WebView2 Runtime。到微软官网搜索「WebView2 Evergreen Standalone Installer」下载安装一次即可；Win11 与近期 Win10 通常已自带。详细异常会写入程序目录 build/error.log。
不装 exe，能直接看课程吗？
可以。课程是纯静态 HTML：解压 zip 后用任意现代浏览器打开 course2000/index.html 即可，功能与 exe 内一致（exe 只是提供了原生窗口与启动优化）。
macOS / Linux 怎么用？
两条路：① 浏览器直接打开 course2000/index.html；② 下载 gen_course.py，在本机 python3 gen_course.py 生成课程页并学习（需 Python 3.8+，无需第三方库）。详见「使用说明」。
换电脑 / 换文件夹，学习进度会丢吗？
课程站本身不记录个人进度，换环境把整个文件夹拷过去即可。exe 会在程序目录生成 cache/ 缓存目录，删除它不影响课程内容，只是首次加载略慢。
PPTX 课件在哪里？
PPTX 课件已打包在 Course2000-Windows.zip 内的 Course2000-PPTX课件-2007课/ 文件夹：2007 课一课一个文件，另有带 2007 条超链接的「总目录」和检索页；用 PowerPoint / WPS 打开即可（先完整解压 zip，勿在压缩包内双击）。
zip 校验值怎么用？
Windows PowerShell 执行 Get-FileHash Course2000-Windows.zip -Algorithm MD5，与页面值比对一致即说明文件完整未被篡改。
