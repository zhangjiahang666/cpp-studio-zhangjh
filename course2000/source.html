NON-WINDOWS

非 Windows 机型使用步骤

下载 gen_course.py（23 KB）

点此下载，或直接复制本页下方全文保存为 gen_course.py。

确认 Python 3

终端执行 python3 --version；macOS / Linux 通常自带，无需安装任何第三方库。

运行生成

改成自己的课程

def tag_spans(tags):
    out = []
    for t in tags.split("/"):
        color = {"HTML": HTML, "CSS": CSS, "JS": JS}.get(t, "#98A2B8")
        out.append(f'<span class="tag" style="background:{color}1f;color:{color};border:1px solid {color}55">{t}</span>')
    return "".join(out)
