更新日志

v1.8 2026-10-24 当前版本

多语言 · 双语界面

  • 评测支持多种编程语言：C++ / Python / Java 三选一。单题、多题、对拍、造数据、随机数据全流程按所选语言走对应运行时——C++ 用 g++ 编译，Python 用解释器直跑，Java 用 javac 编译、java 运行（类名取源文件名）。
  • 按扩展名自动识别：点「浏览」选中 .py / .java 源码时自动切换语言，三个页面（单题 / 多题 / 对拍）的语言下拉始终同步。
  • 运行环境自动探测：Python 解释器与 JDK（javac + java）自动在 PATH 上探测；缺环境时给出明确引导（装哪个、勾哪个选项），不再抛英文异常。
  • 界面语言切换：底栏新增「界面: 中文 / English」，一键把标签页、按钮、表头、分区标题、底栏与状态提示整体切成英文，切回中文完全还原（动态状态栏也不会被覆盖回初始值）。
  • 网页版对拍实验室同步支持多语言：工作台上方新增语言按钮（JavaScript / C++ / Python / Java）。JavaScript 在浏览器内跑，C++ / Python / Java 交给服务端真编译器跑；切换语言时示例代码与代码约定提示同步更新。页面加载自动探测服务端工具链，缺失的语言灰显并给出提示。
  • 兼容性：Python / Java 模式下不再强制要求填写编译器路径；非 C++ 语言的造数据与随机数据也支持用对应语言的 AC 程序跑出标准答案。
v1.7 2026-10-24

更好上手 · 更好看

  • 单题「载入示例」：内置 3 道示例题（A+B / 最大子段和 / 数组排序），一键落盘源码与样例，零配置先跑通，验证环境是否 OK。
  • 对拍「载入挑战」：内置 4 个埋了真 bug 的对拍挑战（初值之坑 / 溢出之坑 / 负数取模 / 整数溢出），生成器 + 主程序 + 暴力一键备齐，落地即对拍揪虫，与官网「对拍实验室」同源。
  • 编译器自动探测：启动扫描 PATH，找到 g++/clang++ 自动填好；找不到时给出 WinLibs 下载引导，底部栏新增「下载编译器」一键打开，新手不再卡在「找不到编译器」。
  • 对拍战绩卡：对拍完成自动生成样式化 HTML 战绩报告（同官网视觉）+ 纯文本备份，浏览器一键查看，方便截图分享到朋友圈 / 小红书参赛。
  • 界面打磨：标题栏加版本号，状态色更直观（AC 绿 / 问题红 / 警告琥珀），暗色对拍日志更聚焦。
v1.6 2026-10-24

体验与健壮性

  • 输出比对归一化：行尾空白与末尾空行不再判错（OI 常规做法），单题评测与对拍同时生效，消除「答案明明对却 WA」的误报。
  • 设置持久化：编译器路径 / C++ 标准 / 优化开关 / 每题分值 / 超时 / 对拍轮数记到 exe 同目录 ojjudge_settings.json，重启不丢；文件损坏时静默回退默认值，不影响启动。
  • 超时可调：底部栏新增「超时(ms)」调节（1–60 秒），单题 / 多题 / 对拍共用，适配慢机器与深度搜索题。
  • 对拍崩溃检测：主程序或暴力程序非零退出（段错误 / 断言失败等）记为「运行异常」并展示退出码，不再误报成「输出不一致」。
  • 问题数据留存：对拍发现输出不一致或运行异常的轮次，输入自动存到工作目录「问题数据」，拿到数据即可离线复现调试。
  • 本次改动全部经过回归测试：输出归一化 6 组边界用例、设置读写往返与损坏降级、真 g++ 编译 / 正误 / 超时判定、对拍崩溃检出与数据留存，18 项全过。
v1.5 2026-10-05

兼容增强

  • 单题 / 多题评测新增 cin/cout 标准输入输出支持：自动把该组 .in 经 stdin 喂给程序并捕获 stdout，与 freopen 写法并存（同时存在时优先取 <题名>.out），兼容洛谷 / tarjano 等 OJ 常规写法。
  • 「随机数据」的 AC 代码改为可选：提供则编译跑出 .out，留空则只生成 .in。
  • README 与说明书同步更新两种写法的约定。
  • 官网新增 macOS / Linux 源码版下载（Python 3 + tkinter，无第三方依赖）；修复编译器诊断输出编码在非 Windows 平台不可用的问题（mbcs → 按平台取编码）。

记录页

  • 新增「记录」页：评测记录（单题 / 多题 / 对拍每次运行自动保存，可回看历史）+ 改动日志。
  • 评测记录持久化到 exe 同目录的「评测记录.json」。
v1.3 导入与稳定

自动导入与稳定性

  • 多题支持启动自动导入：exe 同目录的「题目导入.json」自动填进多题列表，也可手动「导入题目」。
  • 修复多题评测「只测一个就跳过」：改为线程安全队列模式，工作线程不碰界面控件，单题异常不中断后续。
v1.2 对拍不中断

对拍体验

  • 结果表状态徽章：AC 浅绿 / WA 浅红 / 其他浅黄，一眼看清。

随机数据与界面

v1.0 2026-10-04

基础版

  • 单题评测：一个源码 + 一个数据目录，一键出分（AC/WA/TLE、得分、用时、期望/实际）。
  • 多题评测：添加多道题，一键全部评测，结果按题分组汇总。
  • 对拍：主程序 vs 暴力/标程，用随机数据揪 bug。
  • 造数据：自动生成随机 .in 与 .out。
